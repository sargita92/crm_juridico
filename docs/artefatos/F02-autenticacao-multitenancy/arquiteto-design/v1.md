# Design Tecnico — F02 Autenticacao e Multitenancy

## 1. Entidades do dominio

### Tenant (`internal/tenant/domain/`)

```go
type TenantType string   // "PF", "PJ"
type TenantStatus string // "active", "blocked", "inactive"

type Tenant struct {
    ID             string
    Name           string
    Type           TenantType      // PF ou PJ
    Document       string          // CPF ou CNPJ
    Status         TenantStatus
    BlockReason    string          // motivo do bloqueio (opcional)
    CreatedAt      time.Time
    UpdatedAt      time.Time
}
```

### User (`internal/auth/domain/`)

```go
type UserRole string   // "admin", "user"
type UserStatus string // "active", "inactive"

type User struct {
    ID           string
    Name         string
    Email        string
    PasswordHash string
    Role         UserRole
    Status       UserStatus
    CreatedAt    time.Time
    UpdatedAt    time.Time
}
```

### UserTenant (`internal/auth/domain/`) — tabela associativa N:N

```go
type UserTenant struct {
    UserID   string
    TenantID string
}
```

> **Decisao**: relacao N:N entre User e Tenant (um usuario pode pertencer a varios tenants; um tenant pode ter varios usuarios). Isso suporta a Story 5 (selecao de tenant) e o cenario de admin.

## 3. Casos de uso

### LoginUseCase (`internal/auth/application/`)

```go
type LoginInput struct {
    Email    string
    Password string
}

type LoginOutput struct {
    Token    string
    UserID   string
    UserName string
    Role     UserRole
    Tenants  []Tenant // tenants do usuario
}

func (uc *LoginUseCase) Execute(ctx context.Context, input LoginInput) (*LoginOutput, error)
```

**Fluxo**:
1. Buscar usuario por email
2. Verificar status ativo
3. Comparar senha com hash (bcrypt)
4. Buscar tenants do usuario (via UserTenantRepository + TenantRepository)
5. Gerar JWT com claims (user_id, role)
6. Retornar token + dados do usuario + lista de tenants

### SelectTenantUseCase (`internal/auth/application/`)

```go
type SelectTenantInput struct {
    UserID   string
    TenantID string
    Role     UserRole
}

type SelectTenantOutput struct {
    Token string // novo JWT com tenant_id no claim
}

func (uc *SelectTenantUseCase) Execute(ctx context.Context, input SelectTenantInput) (*SelectTenantOutput, error)
```

**Fluxo**:
1. Se admin → qualquer tenant e valido
2. Se user → verificar que tenant_id esta nos tenants do usuario
3. Verificar que o tenant esta ativo
4. Gerar novo JWT com claim tenant_id adicionado
5. Retornar novo token

### ListUserTenantsUseCase (`internal/auth/application/`)

```go
func (uc *ListUserTenantsUseCase) Execute(ctx context.Context, userID string, role UserRole) ([]Tenant, error)
```

**Fluxo**: Se admin → todos os tenants ativos. Se user → tenants vinculados ao usuario.

```go
type PasswordHasher interface {
    Hash(password string) (string, error)

```

Implementacao bcrypt em `internal/auth/infrastructure/`.

### TokenProvider (`internal/auth/domain/`)

```go
type TokenClaims struct {
    UserID   string
    Role     UserRole
    TenantID string // vazio ate selecionar tenant
}

type TokenProvider interface {
    Generate(claims TokenClaims) (string, error)
    Validate(token string) (*TokenClaims, error)
}
```

Implementacao JWT em `internal/auth/infrastructure/`.

## 5. Middlewares (`internal/shared/middleware/`)

### AuthMiddleware

```go
func Auth(tokenProvider TokenProvider) gin.HandlerFunc
```

- Extrai token do cookie `token` (ou header `Authorization: Bearer`)
- Valida token via TokenProvider
- Injeta claims no `gin.Context` (user_id, role, tenant_id)
- 401 se token ausente ou invalido

### TenantMiddleware

```go
func RequireTenant() gin.HandlerFunc
```

- Verifica que `tenant_id` esta presente nos claims do contexto
- 403 se tenant nao selecionado
- Injeta tenant_id no contexto para scoping de queries

### TenantScope (helper de GORM)

```go
func TenantScope(ctx context.Context) func(db *gorm.DB) *gorm.DB
```

- Retorna scope GORM que adiciona `WHERE tenant_id = ?` automaticamente
- Admin bypassa o filtro
- Usado como: `db.Scopes(TenantScope(ctx)).Find(&records)`

## 6. Contratos HTTP

| Metodo | Rota | Handler | Auth | Descricao |
|--------|------|---------|------|-----------|
| GET | `/login` | RenderLogin | nao | Renderiza tela de login |
| POST | `/login` | HandleLogin | nao | Processa login, retorna HX-Redirect ou erro |
| GET | `/select-tenant` | RenderSelectTenant | sim (sem tenant) | Renderiza tela de selecao |
| POST | `/select-tenant` | HandleSelectTenant | sim (sem tenant) | Seleciona tenant, retorna HX-Redirect |
| POST | `/logout` | HandleLogout | sim | Limpa cookie, redirect /login |
| GET | `/dashboard` | RenderDashboard | sim (com tenant) | Placeholder — tela inicial pos-login |

### POST /login

**Request** (form):
```
email=user@example.com&password=secret123
```

**Responses**:
- Sucesso (1 tenant): `HX-Redirect: /dashboard` + set cookie `token`
- Sucesso (N tenants): `HX-Redirect: /select-tenant` + set cookie `token` (sem tenant_id)
- Erro: HTML do card de login com mensagem de erro (200, para hx-swap funcionar)

### POST /select-tenant

**Request** (form):
```
tenant_id=uuid-do-tenant
```

**Response**:
- Sucesso: `HX-Redirect: /dashboard` + set cookie `token` (com tenant_id)
- Erro: 403 se tenant nao pertence ao usuario

## 8. Composicao de dependencias (wire-up)

Adicoes ao `cmd/api/main.go`:

```go
// Tenant
tenantRepo := tenantinfra.NewGormTenantRepository(db)

// Auth
userRepo := authinfra.NewGormUserRepository(db)
userTenantRepo := authinfra.NewGormUserTenantRepository(db)
passwordHasher := authinfra.NewBcryptHasher()
tokenProvider := authinfra.NewJWTProvider(cfg.JWT.Secret, cfg.JWT.Expiration)

loginUC := authapp.NewLoginUseCase(userRepo, userTenantRepo, tenantRepo, passwordHasher, tokenProvider)
selectTenantUC := authapp.NewSelectTenantUseCase(userTenantRepo, tenantRepo, tokenProvider)
listTenantsUC := authapp.NewListUserTenantsUseCase(userTenantRepo, tenantRepo)

authHandler := authhttp.NewHandler(loginUC, selectTenantUC, listTenantsUC)

// Middlewares
authMw := middleware.Auth(tokenProvider)
tenantMw := middleware.RequireTenant()

// Rotas publicas
router.GET("/login", authHandler.RenderLogin)
router.POST("/login", authHandler.HandleLogin)

// Rotas autenticadas (sem tenant obrigatorio)
authGroup := router.Group("/", authMw)
authGroup.GET("/select-tenant", authHandler.RenderSelectTenant)
authGroup.POST("/select-tenant", authHandler.HandleSelectTenant)
authGroup.POST("/logout", authHandler.HandleLogout)

// Rotas autenticadas (com tenant obrigatorio)
tenantGroup := router.Group("/", authMw, tenantMw)
tenantGroup.GET("/dashboard", ...)
```
