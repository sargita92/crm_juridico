# Wireframes e Fluxos — F02 Autenticacao e Multitenancy

## Fluxo de navegacao

```
/login → (credenciais validas)
    ├── usuario tem 1 tenant → /dashboard
    ├── usuario tem N tenants → /select-tenant → /dashboard
    └── admin → /select-tenant (todos) → /dashboard

(credenciais invalidas) → /login (com mensagem de erro inline)
(sem token / token expirado) → redirect /login
```

## Tela: Login (/login)

- Card centralizado (max-width 400px), centralizado vertical e horizontal
- Logo + nome "CRM Juridico" no topo
- Campo email (auto-focus)
- Campo senha com toggle de visibilidade (icone olho)
- Botao "Entrar" (loading state: spinner + "Entrando...", desabilitado durante submit)
- Mensagem de erro generica inline ("Email ou senha invalidos") — sem revelar qual campo falhou
- HTMX: `hx-post="/login"`, `hx-target="#login-card"`, `hx-swap="outerHTML"`
- Sucesso: servidor retorna `HX-Redirect`
- Responsivo: mobile full-width com padding, desktop centralizado

## Tela: Selecao de Tenant (/select-tenant)

- Mesmo layout centralizado do login (max-width 500px)
- Titulo "Selecione o escritorio"
- Lista de cards clicaveis, cada um com:
  - Icone (predio para PJ, pessoa para PF)
  - Nome do tenant
  - Tipo + documento formatado
- Card: hover highlight, loading ao clicar
- HTMX: `hx-post="/select-tenant"` enviando tenant_id
- Sucesso: `HX-Redirect` para /dashboard
- Link "Sair" no rodape (limpa sessao, redirect /login)
- Responsivo: cards empilhados full-width em mobile
