## Vulnerabilidades encontradas e corrigidas

### 1. Vazamento de mensagem de erro interna (MEDIA) — CORRIGIDO

- **Onde**: `HandleSelectTenant` retornava `err.Error()` na resposta JSON
- **Risco**: Mensagens internas (ex: "tenant not found", stack traces) expostas ao cliente
- **Correcao**: Substituido por mensagem generica `"access denied"`
- **Status**: ✅ Corrigido

### 2. Cookie Secure=false (MEDIA) — CORRIGIDO

- **Onde**: `c.SetCookie(...)` com `Secure=false` hardcoded
- **Risco**: Em producao com HTTPS, cookie pode ser interceptado via HTTP
- **Correcao**: Parametro `secureCookie` configuravel via `SERVER_SECURECOOKIE` (default: false para dev, true para prod)
- **Status**: ✅ Corrigido

### 3. Cookie SameSite nao explicito (BAIXA) — CORRIGIDO

- **Onde**: `c.SetCookie()` sem `SameSite`
- **Risco**: Dependia do default do navegador (geralmente Lax, mas nao garantido)
- **Correcao**: `c.SetSameSite(http.SameSiteLaxMode)` explicito antes de SetCookie
- **Status**: ✅ Corrigido
