# Wireframes e Fluxos — F06 Integracao com WhatsApp

## Principio geral

A integracao WhatsApp e a primeira feature da **area do tenant**. Exige um layout proprio (diferente do admin) com sidebar de navegacao do tenant e area principal de conteudo. A experiencia de conversas segue o padrao do **WhatsApp Web**: lista de conversas a esquerda, chat a direita.

---

## Layout do Tenant

O layout do tenant segue a mesma estrutura basica do admin (sidebar + conteudo), mas com navegacao propria.

```
┌────────────────────────────────────────────────────────────────────┐
│ [=]  CRM Juridico — Escritorio XYZ                    [Conectar]  │
├──────────┬─────────────────────────────────────────────────────────┤
│ Sidebar  │                                                         │
│          │                Area de conteudo                          │
│ WhatsApp │                                                         │
│ Leads    │                                                         │
│ Config   │                                                         │
│          │                                                         │
│          │                                                         │
│          │                                                         │
│          │                                                         │
├──────────┴─────────────────────────────────────────────────────────┤
│ Tenant: Escritorio XYZ               [Usuario] [Sair]             │
└────────────────────────────────────────────────────────────────────┘
```

### Sidebar do tenant
- **WhatsApp** (icone: balao de mensagem) → /tenant/whatsapp
- **Leads** (icone: funil) → /tenant/leads (F07, desabilitado por ora)
- **Configuracoes** (icone: engrenagem) → /tenant/settings (futuro)

### Header
- Titulo do tenant (nome do escritorio/empresa)
- Botao "Conectar WhatsApp" ou indicador de status (conectado/desconectado)

---

## Fluxo de navegacao

```
/tenant/dashboard → sidebar
    ├── "WhatsApp" → /tenant/whatsapp
    │     ├── estado "nao conectado" → exibe tela de conexao (QR code)
    │     └── estado "conectado" → exibe interface de conversas
    │           ├── lista de conversas (sidebar esquerda)
    │           └── clique em conversa → chat (area direita)
    └── "Leads" → /tenant/leads (F07, desabilitado)
```

## Tela: Conexao WhatsApp (/tenant/whatsapp — nao conectado)

Exibida quando o tenant ainda nao conectou um numero de WhatsApp.

### Wireframe

```
┌──────────────────────────────────────────────────────────────────┐
│                                                                    │
│                    ┌────────────────────┐                          │
│                    │                    │                          │
│                    │    ┌──────────┐    │                          │
│                    │    │ QR CODE  │    │                          │
│                    │    │          │    │                          │
│                    │    │          │    │                          │
│                    │    └──────────┘    │                          │
│                    │                    │                          │
│                    └────────────────────┘                          │
│                                                                    │
│              Conecte seu WhatsApp ao CRM                          │
│                                                                    │
│         1. Abra o WhatsApp no seu celular                         │
│         2. Toque em "Aparelhos conectados"                        │
│         3. Escaneie o QR code acima                               │
│                                                                    │
│                    Status: Aguardando leitura...                   │
│                                                                    │
└──────────────────────────────────────────────────────────────────┘
```

### Componentes e estados

**QR Code**
- Exibido em card centralizado (max-width 400px)
- Tamanho do QR: 256x256px
- Atualizado automaticamente via polling HTMX (a cada 30s, pois QR expira)
- HTMX: `hx-get="/tenant/whatsapp/qr"` com `hx-trigger="load, every 30s"` e `hx-target="#qr-container"`

**Status da conexao**
- "Aguardando leitura..." (cinza, com spinner)
- "Conectando..." (amarelo, com spinner)
- "Conectado!" (verde, com check) → redireciona automaticamente para conversas
- "Erro na conexao. Tente novamente." (vermelho, com botao "Gerar novo QR")
- HTMX: `hx-get="/tenant/whatsapp/status"` com `hx-trigger="every 3s"` e `hx-target="#connection-status"`

**Instrucoes**
- Texto passo a passo (3 passos simples)
- Icones ilustrativos ao lado de cada passo

### Responsivo (mobile)
- Card de QR code ocupa largura total
- QR code reduzido para 200x200px
- Instrucoes empilhadas abaixo

## Componente: Lista de Conversas (sidebar esquerda)

### Header
- Titulo "Conversas" ou "WhatsApp"
- Campo de busca (placeholder: "Buscar conversa...")
  - HTMX: `hx-get="/tenant/whatsapp/conversations"` com `hx-trigger="input changed delay:300ms"` e `hx-target="#conversations-list"`

### Item de conversa
```
┌──────────────────────────────────────┐
│ [Avatar]  Nome do Contato     10:32  │
│           Preview da ultima msg...   │
│                              [●] 3   │
└──────────────────────────────────────┘
```

- **Avatar**: circulo com iniciais do nome (cores geradas por hash do nome)
- **Nome**: nome do contato (truncado se longo)
- **Hora**: hora da ultima mensagem (se hoje) ou "ontem" ou data
- **Preview**: preview da ultima mensagem (truncado, max 1 linha)
- **Badge de nao lidas**: circulo com numero (cor primaria, aparece apenas se > 0)
- **Conversa selecionada**: fundo destacado (cor primaria com opacidade)

### Ordenacao
- Mais recente primeiro (por ultima mensagem)

### HTMX
- Lista carregada via `hx-get="/tenant/whatsapp/conversations"` com `hx-trigger="load"`
- Clique na conversa: `hx-get="/tenant/whatsapp/conversations/:id"` com `hx-target="#chat-area"` e `hx-push-url="true"`
- Atualizacao em tempo real via SSE: `hx-ext="sse"` com `sse-connect="/tenant/whatsapp/events"` e `sse-swap="conversation-update"` no `#conversations-list`

### Estados
- **Carregando**: skeleton de 5 itens (retangulos cinza animados)
- **Vazio**: "Nenhuma conversa ainda. As conversas aparecerao quando alguem enviar uma mensagem pelo WhatsApp."
- **Erro**: "Erro ao carregar conversas. [Tentar novamente]"
- **Busca sem resultado**: "Nenhuma conversa encontrada para 'termo'"

## Componente: Area de Chat (coluna direita)

### Header do chat
```
┌──────────────────────────────────────────────────────────────────┐
│ [Avatar]  Maria Silva                               ● Conectado │
└──────────────────────────────────────────────────────────────────┘
```

- Avatar + nome do contato
- Indicador de status da conexao WhatsApp (conectado/desconectado)
- Em mobile: botao voltar [<] no lugar do avatar

### Area de mensagens

- Scroll vertical com mensagens em ordem cronologica (mais antigas no topo)
- Auto-scroll para a ultima mensagem ao abrir conversa
- Auto-scroll ao receber nova mensagem (se ja estiver no final do scroll)
- Agrupamento visual por dia (separador "Hoje", "Ontem", "05/04/2026")

**Balao de mensagem recebida (esquerda)**
```
    ┌──────────────────────────┐
    │ Texto da mensagem        │
    │ recebida aqui      10:30 │
    └──────────────────────────┘
```
- Fundo: cinza claro (#f0f0f0)
- Alinhado a esquerda
- Hora no canto inferior direito do balao

**Balao de mensagem enviada (direita)**
```
  ┌──────────────────────────┐
  │ Texto da mensagem        │
  │ enviada aqui       10:31 │
  └──────────────────────────┘
```
- Fundo: verde claro (#dcf8c6, similar ao WhatsApp)
- Alinhado a direita
- Hora no canto inferior direito do balao

### Campo de envio

```
┌──────────────────────────────────────────────────────────────────┐
│ [Digite sua mensagem...                              ] [Enviar] │
└──────────────────────────────────────────────────────────────────┘
```

- Input de texto (textarea auto-expansivel, max 5 linhas)
- Botao "Enviar" (icone de seta ou aviao de papel, cor primaria)
- Enter envia, Shift+Enter quebra linha
- Botao desabilitado quando campo vazio
- HTMX: `hx-post="/tenant/whatsapp/conversations/:id/messages"` com `hx-target="#messages-area"` e `hx-swap="beforeend"` (append)
- Apos envio: limpar campo, scroll para nova mensagem

### Estados do chat
- **Nenhuma conversa selecionada**: area vazia com ilustracao + "Selecione uma conversa para comecar"
- **Carregando mensagens**: spinner centralizado
- **Conversa sem mensagens**: "Inicio da conversa com [nome]"
- **Erro ao carregar**: "Erro ao carregar mensagens. [Tentar novamente]"
- **Erro ao enviar**: toast vermelho "Falha ao enviar mensagem. [Reenviar]"
- **Enviando**: balao da mensagem com opacidade reduzida + spinner pequeno ate confirmacao

### HTMX — Atualizacao em tempo real (SSE)

Novas mensagens chegam via Server-Sent Events:

- Conexao SSE: `hx-ext="sse"` com `sse-connect="/tenant/whatsapp/events"`
- Evento `new-message`: append do balao HTML no `#messages-area`
- Evento `conversation-update`: atualiza item na lista de conversas (preview, hora, badge)
- Se a conversa afetada nao e a aberta: incrementa badge de nao lidas na lista

**Fallback se SSE desconectar:**
- Reconnect automatico (padrao SSE do navegador)
- Polling HTMX a cada 5s como fallback: `hx-get="/tenant/whatsapp/conversations/:id/messages/new?after=:last_id"` com `hx-trigger="every 5s"` e `hx-target="#messages-area"` e `hx-swap="beforeend"`

## Padroes de interacao

### HTMX
- Lista de conversas e chat sao fragmentos independentes
- SSE para atualizacoes em tempo real (novas mensagens, atualizacao da lista)
- Polling como fallback para SSE
- Campo de busca com debounce de 300ms
- Envio de mensagem via `hx-post` com append no chat
- Navegacao entre conversas sem reload da pagina (apenas troca o fragmento do chat)

### Feedback visual
- Toast de sucesso ao enviar mensagem (discreto, some em 2s)
- Toast de erro ao falhar envio (permanece ate ser fechado, com botao "Reenviar")
- Skeleton loading para lista de conversas
- Spinner para carregamento de mensagens
- Balao com opacidade reduzida enquanto mensagem esta "enviando"
- Badge numerico de mensagens nao lidas
- Separadores de data entre mensagens

### Acessibilidade
- Navegacao por teclado na lista de conversas (setas cima/baixo)
- Enter para abrir conversa selecionada
- Enter para enviar mensagem no campo de texto
- Aria-labels nos botoes de acao
- Aria-live region para novas mensagens (leitores de tela)

### Responsivo
- **Desktop (>= 1024px)**: layout 2 colunas (lista 320px + chat restante)
- **Tablet (768-1023px)**: layout 2 colunas (lista 280px + chat restante)
- **Mobile (< 768px)**: coluna unica, alterna entre lista e chat
  - Lista de conversas: tela cheia
  - Clique em conversa: transicao para tela de chat
  - Botao voltar [<] no header do chat retorna para lista
  - HTMX: `hx-get` com `hx-target="#main-content"` e `hx-push-url="true"` para navegacao

## Fluxo completo do usuario

```
1. Usuario acessa /tenant/whatsapp
   ├── Se nao conectado → tela de QR code
   │     ├── Escaneia QR → status muda para "conectado"
   │     └── Redireciona para interface de conversas
   └── Se conectado → interface de conversas
         ├── Ve lista de conversas (vazia ou com conversas)
         ├── Clica em conversa → ve chat com historico
         ├── Digita e envia mensagem → balao aparece no chat
         ├── Recebe mensagem → balao aparece automaticamente (SSE)
         └── Nova conversa aparece na lista ao receber msg de novo contato
```
