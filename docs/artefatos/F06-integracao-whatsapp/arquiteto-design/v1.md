# Design Tecnico — F06 Integracao com WhatsApp

## Visao geral

F06 cria o modulo `whatsapp` com dominio proprio (Contact, Conversation, Message), abstrai o provider WhatsApp via interface (whatsmeow para dev, Meta Business API no futuro), e introduz o **layout do tenant** — primeira feature da area do tenant. O modulo e long-running (mantém conexao WebSocket com WhatsApp) e usa SSE para atualizar a interface em tempo real.

## 1. Dominio

### 1.1 Entidade Contact

```go
// internal/whatsapp/domain/contact.go

type Contact struct {
    ID         string
    TenantID   string
    Name       string
    Phone      string
    WhatsAppID string    // identificador unico do WhatsApp (JID)
    CreatedAt  time.Time
    UpdatedAt  time.Time
}

const MaxContactNameLength = 255

func NewContact(id, tenantID, name, phone, whatsappID string) (*Contact, error) {
    if tenantID == "" {
        return nil, ErrTenantIDRequired
    }
    if phone == "" {
        return nil, ErrContactPhoneRequired
    }
    if whatsappID == "" {
        return nil, ErrContactWhatsAppIDRequired
    }
    if len(name) > MaxContactNameLength {
        return nil, ErrContactNameTooLong
    }
    now := time.Now()
    return &Contact{
        ID: id, TenantID: tenantID, Name: name,
        Phone: phone, WhatsAppID: whatsappID,
        CreatedAt: now, UpdatedAt: now,
    }, nil
}

func (c *Contact) UpdateName(name string) {
    if name != "" && name != c.Name {
        c.Name = name
        c.UpdatedAt = time.Now()
    }
}
```

### 1.2 Entidade Conversation

```go
// internal/whatsapp/domain/conversation.go

type ConversationStatus string

const (
    ConversationStatusOpen   ConversationStatus = "open"
    ConversationStatusClosed ConversationStatus = "closed"
)

type Conversation struct {
    ID            string
    TenantID      string
    ContactID     string
    Status        ConversationStatus
    LastMessageAt time.Time
    UnreadCount   int
    CreatedAt     time.Time
    UpdatedAt     time.Time
}

func NewConversation(id, tenantID, contactID string) (*Conversation, error) {
    if tenantID == "" {
        return nil, ErrTenantIDRequired
    }
    if contactID == "" {
        return nil, ErrContactIDRequired
    }
    now := time.Now()
    return &Conversation{
        ID: id, TenantID: tenantID, ContactID: contactID,
        Status: ConversationStatusOpen, LastMessageAt: now,
        UnreadCount: 0, CreatedAt: now, UpdatedAt: now,
    }, nil
}

func (c *Conversation) Close() {
    c.Status = ConversationStatusClosed
    c.UpdatedAt = time.Now()
}

func (c *Conversation) RecordMessage(timestamp time.Time, incoming bool) {
    c.LastMessageAt = timestamp
    c.UpdatedAt = time.Now()
    if incoming {
        c.UnreadCount++
    }
}

func (c *Conversation) MarkRead() {
    c.UnreadCount = 0
    c.UpdatedAt = time.Now()
}
```

### 1.3 Entidade Message

```go
// internal/whatsapp/domain/message.go

type MessageDirection string

const (
    MessageDirectionIncoming MessageDirection = "incoming"
    MessageDirectionOutgoing MessageDirection = "outgoing"
)

type MessageType string

const (
    MessageTypeText MessageType = "text"
)

type MessageStatus string

const (
    MessageStatusPending MessageStatus = "pending"
    MessageStatusSent    MessageStatus = "sent"
    MessageStatusFailed  MessageStatus = "failed"
)

type Message struct {
    ID             string
    ConversationID string
    Direction      MessageDirection
    Content        string
    Type           MessageType
    Status         MessageStatus
    WhatsAppMsgID  string    // ID da mensagem no WhatsApp (para dedup)
    Timestamp      time.Time
    CreatedAt      time.Time
}

const MaxMessageContentLength = 4096

func NewMessage(id, conversationID string, direction MessageDirection, content string, msgType MessageType, whatsappMsgID string, timestamp time.Time) (*Message, error) {
    if conversationID == "" {
        return nil, ErrConversationIDRequired
    }
    if content == "" {
        return nil, ErrMessageContentRequired
    }
    if len(content) > MaxMessageContentLength {
        return nil, ErrMessageContentTooLong
    }
    status := MessageStatusSent
    if direction == MessageDirectionOutgoing {
        status = MessageStatusPending
    }
    return &Message{
        ID: id, ConversationID: conversationID,
        Direction: direction, Content: content,
        Type: msgType, Status: status,
        WhatsAppMsgID: whatsappMsgID, Timestamp: timestamp,
        CreatedAt: time.Now(),
    }, nil
}

func (m *Message) MarkSent() {
    m.Status = MessageStatusSent
}

func (m *Message) MarkFailed() {
    m.Status = MessageStatusFailed
}
```

### 1.6 Interface do Provider WhatsApp

```go
// internal/whatsapp/domain/provider.go

// WhatsAppProvider abstrai a conexao com WhatsApp.
// Implementacoes: whatsmeow (dev), Meta Business API (prod futuro).
type WhatsAppProvider interface {
    // Connect inicia a conexao e retorna o QR code para escaneamento.
    // O canal qrChan recebe atualizacoes do QR code (novo QR a cada expiracao).
    Connect(ctx context.Context, tenantID string) (qrChan <-chan string, err error)

    // Disconnect encerra a conexao do tenant.
    Disconnect(ctx context.Context, tenantID string) error

    // IsConnected retorna se o tenant esta conectado.
    IsConnected(tenantID string) bool

    // SendMessage envia uma mensagem de texto para um numero.
    SendMessage(ctx context.Context, tenantID, recipientWhatsAppID, content string) (whatsappMsgID string, err error)

    // SetMessageHandler registra o callback para mensagens recebidas.
    SetMessageHandler(handler IncomingMessageHandler)
}

// IncomingMessageHandler e o callback chamado quando uma mensagem chega.
type IncomingMessageHandler func(ctx context.Context, event IncomingMessage)

type IncomingMessage struct {
    TenantID      string
    SenderJID     string // WhatsApp ID do remetente
    SenderName    string
    SenderPhone   string
    Content       string
    WhatsAppMsgID string
    Timestamp     time.Time
}
```

```go
// internal/whatsapp/domain/events.go

type EventType string

const (
    EventNewMessage        EventType = "new-message"
    EventConversationUpdate EventType = "conversation-update"
)

type Event struct {
    Type     EventType
    TenantID string
    Payload  interface{}
}

// EventBus distribui eventos para clientes SSE conectados.
type EventBus interface {
    // Publish envia evento para todos os subscribers do tenant.
    Publish(event Event)

    // Subscribe cria um canal para receber eventos de um tenant.
    Subscribe(tenantID string) (<-chan Event, func())
}
```

| Metodo | Rota | Descricao | Auth |
|--------|------|-----------|------|
| GET | /tenant/whatsapp/events | Stream SSE de eventos | auth + tenant |

Eventos SSE:
- `new-message`: HTML do balao de mensagem (append no chat)
- `conversation-update`: HTML do item de conversa (replace na lista)

### 3.4 Request/Response

**POST /tenant/whatsapp/conversations/:id/messages**
```
Request (form):
  content: string (obrigatorio, max 4096)

Response (HTML fragment):
  balao de mensagem enviada (append no chat)

Erro:
  toast HTML com mensagem de erro
```

**GET /tenant/whatsapp/conversations?search=termo&page=1**
```
Response (HTML fragment):
  lista de itens de conversa
```

**GET /tenant/whatsapp/conversations/:id?after=msg_id**
```
Response (HTML fragment):
```

## 7. Composicao de dependencias (wire-up)

### Module

```go
// internal/whatsapp/module.go

type WhatsAppModule struct {
    handler *http.WhatsAppHandler
}

func NewModule(db *gorm.DB, provider WhatsAppProvider) *WhatsAppModule {
    // Repos
    contactRepo := infrastructure.NewGormContactRepository(db)
    conversationRepo := infrastructure.NewGormConversationRepository(db)
    messageRepo := infrastructure.NewGormMessageRepository(db)

    // Event bus
    eventBus := infrastructure.NewMemoryEventBus()

    // Use cases
    receiveMessageUC := application.NewReceiveMessageUseCase(contactRepo, conversationRepo, messageRepo, eventBus)
    sendMessageUC := application.NewSendMessageUseCase(conversationRepo, messageRepo, contactRepo, provider, eventBus)
    listConversationsUC := application.NewListConversationsUseCase(conversationRepo)
    getMessagesUC := application.NewGetConversationMessagesUseCase(conversationRepo, messageRepo)
    connectUC := application.NewConnectWhatsAppUseCase(provider)
    statusUC := application.NewGetConnectionStatusUseCase(provider)
    disconnectUC := application.NewDisconnectWhatsAppUseCase(provider)

    // Registrar handler de mensagens recebidas no provider
    provider.SetMessageHandler(func(ctx context.Context, event domain.IncomingMessage) {
        receiveMessageUC.Execute(ctx, event)
    })

    // Handler HTTP
    handler := http.NewWhatsAppHandler(
        sendMessageUC, listConversationsUC, getMessagesUC,
        connectUC, statusUC, disconnectUC, eventBus,
    )

    return &WhatsAppModule{handler: handler}
}

func (m *WhatsAppModule) Name() string { return "whatsapp" }

func (m *WhatsAppModule) RegisterRoutes(router *gin.Engine, authMw, adminMw gin.HandlerFunc) {
    // WhatsApp usa authMw + tenantMw (nao adminMw)
    // Nota: precisara receber tenantMw tambem, ou extrair do router
    m.handler.RegisterRoutes(router, authMw)
}
```

### Atualizacao do main.go

```go
// Adicionar ao main.go:

// Provider WhatsApp (whatsmeow)
whatsmeowProvider := infrastructure.NewWhatsmeowProvider(db, log)
defer whatsmeowProvider.Shutdown()

// Modulo WhatsApp
whatsappMod := whatsapp.NewModule(db, whatsmeowProvider)

modules := []module.Module{tenantMod, specialistMod, documentMod, mcpMod, whatsappMod}
```

**Nota sobre Module interface**: o modulo whatsapp precisa receber `tenantMw` alem de `authMw` e `adminMw`. Duas opcoes:
1. Passar `tenantMw` como parametro extra no RegisterRoutes (atualizar interface)
2. Receber `tenantMw` no construtor do modulo

**Decisao**: atualizar a interface `Module.RegisterRoutes` para receber um struct de middlewares em vez de parametros posicionais:

```go
// internal/shared/module/module.go (atualizar)

type Middlewares struct {
    Auth   gin.HandlerFunc
    Tenant gin.HandlerFunc
    Admin  gin.HandlerFunc
}

type Module interface {
    Name() string
    RegisterRoutes(router *gin.Engine, mw Middlewares)
}
```

Isso requer atualizar os modulos existentes (tenant, specialist, document, mcp) para usar a nova assinatura. Mudanca retrocompativel — todos ja recebem os mesmos middlewares.

- `whatsapp_messages_sent_total{tenant_id, status}` — total de mensagens enviadas (sent/failed)

- Toda operacao com `tenant_id`, `contact_id`, `conversation_id`
