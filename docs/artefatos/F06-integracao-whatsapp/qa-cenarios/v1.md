# Cenarios de Teste — F06 Integracao com WhatsApp

## Story 1: Cadastro automatico de contatos

### CT-01: Contato criado ao receber primeira mensagem
- **Dado** que tenant esta conectado ao WhatsApp
- **E** numero +5511999990001 nunca enviou mensagem
- **Quando** sistema recebe mensagem desse numero
- **Entao** contato e criado com phone="+5511999990001" e whatsapp_id preenchido
- **E** nome e preenchido a partir do perfil WhatsApp

### CT-02: Contato reutilizado ao receber mensagem de numero existente
- **Dado** que contato com whatsapp_id="5511999990001@s.whatsapp.net" ja existe para o tenant
- **Quando** sistema recebe nova mensagem desse numero
- **Entao** nenhum contato novo e criado
- **E** mensagem e associada ao contato existente

### CT-03: Contato criado com dados parciais (apenas telefone)
- **Dado** que remetente nao tem nome configurado no perfil WhatsApp
- **Quando** sistema recebe mensagem
- **Entao** contato e criado com name="" e phone preenchido

### CT-04: Contatos isolados por tenant
- **Dado** que tenant A e tenant B estao conectados
- **E** mesmo numero envia mensagem para ambos
- **Quando** sistema processa as mensagens
- **Entao** sao criados 2 contatos separados (um para cada tenant)
- **E** tenant A nao ve contatos de tenant B

### CT-05: Nome do contato atualizado quando perfil muda
- **Dado** que contato existe com nome "Maria"
- **Quando** nova mensagem chega e perfil WhatsApp agora mostra "Maria Silva"
- **Entao** nome do contato e atualizado para "Maria Silva"

### CT-06: Nome do contato com 256 caracteres
- **Dado** que perfil WhatsApp tem nome com 256 caracteres
- **Quando** sistema recebe mensagem
- **Entao** mensagem de erro "Nome excede o tamanho maximo" e registrada
- **E** contato e criado com nome truncado ou vazio

## Cenarios OWASP

### A01 — Broken Access Control

### CT-63: Acesso nao autenticado a /tenant/whatsapp
- **Dado** que nao ha token de autenticacao
- **Quando** tenta acessar /tenant/whatsapp
- **Entao** recebe erro 401

### CT-64: Acesso sem tenant selecionado
- **Dado** que usuario esta autenticado mas sem tenant selecionado
- **Quando** tenta acessar /tenant/whatsapp
- **Entao** recebe erro 403

### CT-65: Acesso a conversa de outro tenant
- **Dado** que usuario do tenant A conhece ID de conversa do tenant B
- **Quando** tenta GET /tenant/whatsapp/conversations/:id_do_tenant_b
- **Entao** recebe erro 404 (conversa nao encontrada — nao revela existencia)

### CT-66: Envio de mensagem em conversa de outro tenant
- **Dado** que usuario do tenant A conhece ID de conversa do tenant B
- **Quando** tenta POST /tenant/whatsapp/conversations/:id_do_tenant_b/messages
- **Entao** recebe erro 404

### CT-67: Acesso ao SSE de outro tenant
- **Dado** que usuario do tenant A se conecta ao SSE
- **Quando** mensagem chega para tenant B
- **Entao** tenant A nao recebe o evento

### CT-68: Desconectar WhatsApp de outro tenant
- **Dado** que usuario do tenant A tenta POST /tenant/whatsapp/disconnect com tenant_id de B
- **Quando** sistema processa
- **Entao** apenas o WhatsApp do tenant do usuario e afetado (tenant_id vem do token, nao do request)

### CT-69: Admin nao acessa area do tenant diretamente
- **Dado** que usuario admin tenta acessar /tenant/whatsapp sem selecionar tenant
- **Quando** sistema processa
- **Entao** recebe erro 403 (admin precisa selecionar tenant primeiro)

### A03 — Injection

### CT-70: SQL injection na busca de conversas
- **Dado** que usuario busca por `'; DROP TABLE conversations; --`
- **Quando** envia busca
- **Entao** busca retorna 0 resultados (sem erro de SQL)
- **E** tabela conversations permanece intacta

### CT-71: SQL injection no envio de mensagem
- **Dado** que usuario envia mensagem `'; DROP TABLE messages; --`
- **Quando** sistema processa
- **Entao** texto e tratado como conteudo literal da mensagem

### CT-72: XSS no conteudo de mensagem recebida
- **Dado** que contato envia mensagem `<script>alert('xss')</script>`
- **Quando** mensagem e exibida no chat
- **Entao** HTML e escapado (texto exibido, script nao executado)

### CT-73: XSS no conteudo de mensagem enviada
- **Dado** que usuario envia mensagem `<img onerror=alert(1) src=x>`
- **Quando** mensagem e exibida no chat
- **Entao** HTML e escapado

### CT-74: XSS no nome do contato
- **Dado** que perfil WhatsApp tem nome `<script>document.cookie</script>`
- **Quando** nome e exibido na lista de conversas e no header do chat
- **Entao** HTML e escapado

### CT-75: Injection no campo de busca
- **Dado** que usuario busca por `" onmouseover="alert(1)`
- **Quando** termo e exibido no resultado "Nenhuma conversa encontrada para '...'"
- **Entao** HTML e escapado
