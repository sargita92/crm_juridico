# Wireframes e Fluxos — F04 CRUD de Especialistas (Admin)

## Fluxo de navegacao

```
/admin/dashboard → sidebar "Especialistas" → /admin/specialists (listagem)
    ├── botao "Novo Especialista" → /admin/specialists/new (formulario)
    ├── clique na linha → /admin/specialists/:id (detalhe)
    │     ├── botao "Editar" → /admin/specialists/:id/edit (formulario)
    │     ├── botao "Desativar" → modal de confirmacao
    │     ├── botao "Reativar" → acao direta com confirmacao
    │     └── secao "Tenants" → gerenciamento de associacoes
    └── filtros e busca atuam inline (HTMX, sem reload)
```

## Tela: Listagem de Especialistas (/admin/specialists)

### Header
- Titulo "Especialistas"
- Botao "Novo Especialista" (canto direito, cor primaria)

### Filtros (barra acima da tabela)
- Campo de busca (placeholder: "Buscar por nome...")
  - HTMX: `hx-get="/admin/specialists"` com `hx-trigger="input changed delay:300ms"` e `hx-target="#specialists-table"`
- Select de status: Todos | Ativo | Inativo
  - HTMX: `hx-get` no change

### Tabela
- Colunas: Nome | Descricao | Status | Tenants | Criado em | Acoes
- Descricao truncada (max 80 caracteres, com "...")
- Status com badge colorido:
  - Ativo: verde
  - Inativo: cinza
- Coluna Tenants: numero de tenants associados (ex: "3 tenants")
- Coluna Acoes: icone de visualizar (olho)
- Linha clicavel (leva ao detalhe)
- Paginacao no rodape:
  - "Mostrando 1-20 de 45"
  - Botoes: Anterior | Proxima
  - HTMX: `hx-get` com page param, `hx-target="#specialists-table"`

### Estado vazio
- Icone ilustrativo + "Nenhum especialista encontrado"
- Se ha filtros ativos: "Limpar filtros"

## Tela: Formulario de Criacao (/admin/specialists/new)

### Header
- Breadcrumb: Especialistas > Novo Especialista
- Titulo "Novo Especialista"

### Formulario (card centralizado, max-width 700px)
- Campo **Nome** (text, obrigatorio, placeholder: "Nome do especialista")
- Campo **Descricao** (textarea, opcional, placeholder: "Descricao breve do especialista...", max 500 caracteres)
  - Contador de caracteres no canto inferior direito
- Campo **Prompt** (textarea grande, obrigatorio, placeholder: "Defina o comportamento do especialista...")
  - Altura minima: 300px
  - Contador de caracteres: "X / 10.000"
  - Fonte monoespacada para facilitar leitura
  - Dica abaixo: "O prompt define como o especialista se comporta ao atender leads."
- Botao "Salvar" (cor primaria, loading state: spinner + "Salvando...")
- Botao "Cancelar" (cor neutra, volta para listagem)
- HTMX: `hx-post="/admin/specialists"`, `hx-target="#form-container"`, `hx-swap="outerHTML"`
- Sucesso: `HX-Redirect` para detalhe do especialista criado
- Erro de validacao: re-renderiza formulario com mensagens inline nos campos

## Tela: Detalhe do Especialista (/admin/specialists/:id)

### Header
- Breadcrumb: Especialistas > Nome do Especialista
- Titulo: nome do especialista
- Badge: status (colorido)

### Card de informacoes
- **Nome**: valor
- **Descricao**: texto completo
- **Status**: badge colorido
- **Criado em**: data formatada
- **Atualizado em**: data formatada

### Secao: Prompt
- Card separado com titulo "Prompt"
- Texto do prompt exibido em bloco com fundo cinza claro e fonte monoespacada
- Botao "Editar Prompt" (canto superior direito do card) → navega para edicao com foco no campo prompt

### Secao: Tenants Associados
- Card separado com titulo "Tenants Associados"
- Botao "Gerenciar Tenants" (canto superior direito do card) → abre modal de associacao
- Lista dos tenants associados:
  - Nome | Tipo | Status | Botao "Remover" (X vermelho)
  - Remover: HTMX `hx-delete="/admin/specialists/:id/tenants/:tenant_id"` com `hx-confirm="Desassociar este tenant?"`
  - `hx-target="#tenants-section"`, `hx-swap="outerHTML"`
- Estado vazio: "Nenhum tenant associado" + botao "Associar Tenant"
- HTMX: secao carregada via `hx-get="/admin/specialists/:id/tenants"` com `hx-trigger="load"`

### Acoes (barra de botoes)
- **Editar** (cor primaria) → navega para formulario de edicao
- **Desativar** (vermelho, exibido se ativo) → abre modal
- **Reativar** (verde, exibido se inativo) → acao com confirmacao inline
- **Voltar** (neutro) → volta para listagem

## Modal: Desativar Especialista

- Overlay escuro + card centralizado (max-width 480px)
- Titulo: "Desativar Especialista"
- Texto: "Tem certeza que deseja desativar o especialista [nome]? Ele nao podera ser associado a novos tenants enquanto estiver inativo."
- Nota: "Tenants ja associados manterao a associacao, mas o especialista nao atendera novos leads."
- Botao "Desativar" (vermelho, loading state)
- Botao "Cancelar" (neutro, fecha modal)
- HTMX: `hx-post="/admin/specialists/:id/deactivate"`, `hx-target="#specialist-detail"`, `hx-swap="outerHTML"`
- Sucesso: fecha modal, atualiza detalhe com novo status

---

## Modal: Gerenciar Tenants (Associacao)

- Overlay escuro + card centralizado (max-width 600px)
- Titulo: "Associar Tenants"
- Campo de busca (placeholder: "Buscar tenant por nome...")
  - HTMX: `hx-get="/admin/specialists/:id/tenants/available"` com `hx-trigger="input changed delay:300ms"` e `hx-target="#available-tenants"`
- Lista de tenants disponiveis (apenas ativos, nao associados):
  - Checkbox | Nome | Tipo | Documento
  - Tenants ja associados aparecem desabilitados com label "Ja associado"
  - Tenants inativos/bloqueados nao aparecem
- Botao "Associar Selecionados" (cor primaria, loading state)
- Botao "Cancelar" (neutro, fecha modal)
- HTMX: `hx-post="/admin/specialists/:id/tenants"`, body com array de tenant_ids
- Sucesso: fecha modal, atualiza secao de tenants no detalhe

## Padroes de interacao

### HTMX
- Todos os formularios usam HTMX para submit sem reload
- Filtros e busca atualizam apenas a tabela (`hx-target`)
- Paginacao via HTMX (sem reload de pagina)
- Loading states em todos os botoes de acao (spinner + texto)
- Modais renderizados pelo servidor e injetados via HTMX
- Secao de tenants associados carregada via lazy-load (hx-trigger="load")
- Remocao de associacao com confirmacao inline (hx-confirm)

### Feedback visual
- Toast/banner de sucesso apos criar, editar, desativar, reativar, associar, desassociar
- Mensagens de erro inline nos campos do formulario
- Badges coloridos para status
- Confirmacao antes de acoes destrutivas (desativar)
- Contador de caracteres no prompt e descricao

### Campo de prompt
- Textarea com altura minima de 300px
- Fonte monoespacada (facilita leitura de prompts estruturados)
- Contador de caracteres: "X / 10.000"
- Resize vertical habilitado
- Dica contextual abaixo do campo

### Responsivo
- Tabela com scroll horizontal em mobile
- Formularios full-width em mobile
- Modais full-screen em mobile
- Sidebar colapsa em hamburger
- Campo de prompt ocupa 100% da largura em mobile
