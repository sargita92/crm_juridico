# Cenarios de Teste — F04 CRUD de Especialistas (Admin)

## Story 1: Criar Especialista

### CT-01: Criacao com dados validos
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario com nome="Assistente Juridico", descricao="Atende leads de direito civil", prompt="Voce e um assistente..."
- **Entao** especialista e criado com status "active"
- **E** admin e redirecionado para o detalhe do especialista

### CT-02: Criacao sem nome
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario sem nome
- **Entao** mensagem de erro "Nome e obrigatorio" e exibida
- **E** especialista nao e criado

### CT-03: Criacao sem prompt
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario sem prompt
- **Entao** mensagem de erro "Prompt e obrigatorio" e exibida
- **E** especialista nao e criado

### CT-04: Criacao com prompt acima do limite
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario com prompt de 10.001 caracteres
- **Entao** mensagem de erro "Prompt excede o tamanho maximo" e exibida
- **E** especialista nao e criado

### CT-05: Criacao com descricao acima do limite
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario com descricao de 501 caracteres
- **Entao** mensagem de erro "Descricao excede o tamanho maximo" e exibida

### CT-06: Criacao sem descricao (opcional)
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario com nome e prompt validos, sem descricao
- **Entao** especialista e criado com descricao vazia
- **E** admin e redirecionado para o detalhe

## Story 2: Listar Especialistas

### CT-07: Listagem com dados
- **Dado** que existem 25 especialistas cadastrados
- **Quando** admin acessa /admin/specialists
- **Entao** ve os primeiros 20 especialistas (paginados)
- **E** cada linha exibe nome, descricao truncada, status, quantidade de tenants, data de criacao

### CT-08: Listagem vazia
- **Dado** que nao existem especialistas
- **Quando** admin acessa /admin/specialists
- **Entao** mensagem "Nenhum especialista encontrado" e exibida

### CT-09: Busca por nome
- **Dado** que existe especialista "Assistente Juridico"
- **Quando** admin busca por "Juridico"
- **Entao** apenas especialistas com "Juridico" no nome sao exibidos

### CT-10: Filtro por status
- **Dado** que existem especialistas ativos e inativos
- **Quando** admin filtra por status "inactive"
- **Entao** apenas especialistas inativos sao exibidos

### CT-11: Filtros combinados (busca + status)
- **Dado** que existem especialistas ativos e inativos com nomes variados
- **Quando** admin busca "Assistente" e filtra status="active"
- **Entao** apenas especialistas ativos com "Assistente" no nome sao exibidos

### CT-12: Paginacao
- **Dado** que existem 45 especialistas
- **Quando** admin navega para pagina 2
- **Entao** ve especialistas 21-40
- **E** paginacao mostra "Mostrando 21-40 de 45"

## Cenarios OWASP

### A01 — Broken Access Control

### CT-45: Escalacao de privilegio — criar especialista
- **Dado** que usuario "user" tenta POST /admin/specialists
- **Quando** envia request de criacao
- **Entao** recebe 403

### CT-46: Escalacao de privilegio — associar tenant
- **Dado** que usuario "user" tenta POST /admin/specialists/:id/tenants
- **Quando** envia request de associacao
- **Entao** recebe 403

### CT-47: IDOR — acesso a especialista por ID
- **Dado** que usuario "user" conhece o ID de um especialista
- **Quando** tenta GET /admin/specialists/:id
- **Entao** recebe 403

### CT-48: Manipulacao de metodo HTTP
- **Dado** que usuario "user" tenta DELETE /admin/specialists/:id/tenants/:tenant_id
- **Quando** envia request
- **Entao** recebe 403

### A03 — Injection

### CT-49: SQL injection no campo de busca
- **Dado** que admin busca por `'; DROP TABLE specialists; --`
- **Quando** envia busca
- **Entao** busca retorna 0 resultados (sem erro de SQL)
- **E** tabela specialists permanece intacta

### CT-50: SQL injection no campo nome
- **Dado** que admin tenta criar especialista com nome `' OR 1=1 --`
- **Quando** submete formulario
- **Entao** nome e tratado como texto literal

### CT-51: XSS no campo nome
- **Dado** que admin cria especialista com nome `<script>alert('xss')</script>`
- **Quando** especialista aparece na listagem
- **Entao** HTML e escapado (exibido como texto, nao executado)

### CT-52: XSS no campo prompt
- **Dado** que admin cria especialista com prompt contendo `<script>alert('xss')</script>`
- **Quando** prompt e exibido no detalhe
- **Entao** HTML e escapado (exibido como texto, nao executado)

### CT-53: XSS no campo descricao
- **Dado** que admin cria especialista com descricao `<img onerror=alert(1) src=x>`
- **Quando** descricao e exibida na listagem
- **Entao** HTML e escapado (exibido como texto, nao executado)
