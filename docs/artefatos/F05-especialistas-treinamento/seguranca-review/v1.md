# Review de Seguranca — F05 Treinamento de Especialistas

## Resultado: APROVADO (apos correcoes)

## Vulnerabilidades Encontradas e Corrigidas

### 1. UUID validation ausente em guardrail/step/scoring handlers (corrigido)
- **Severidade**: Alta
- **Arquivos**: guardrail_handler.go, step_handler.go, scoring_handler.go
- **Problema**: Path params (:id, :gid, :sid) nao eram validados como UUID antes de queries ao banco
- **Correcao**: Adicionado `validUUID()` em todos os handlers (HandleList, HandleCreate, HandleUpdate, HandleToggle, HandleDelete, HandleMoveUp, HandleMoveDown, HandleGet)
- **Status**: Corrigido

### 2. UUID validation ausente em rotas de associacao doc/MCP (corrigido)
- **Severidade**: Alta
- **Arquivos**: document/handler.go, mcp/handler.go
- **Problema**: HandleListSpecialistDocuments, HandleListAvailableDocuments, HandleAssociateDocuments, HandleListSpecialistMcps, HandleListAvailableMcps, HandleAssociateMcps nao validavam specialist ID
- **Correcao**: Adicionado `validUUID(id)` em todos os handlers de associacao
- **Status**: Corrigido

### 3. Sem limite de tamanho de arquivo no upload (corrigido)
- **Severidade**: Alta
- **Arquivo**: document/handler.go
- **Problema**: Upload aceitava arquivos de tamanho arbitrario, risco de DoS
- **Correcao**: Adicionada constante `maxFileSize = 10MB` e validacao `header.Size > maxFileSize` antes de salvar
- **Status**: Corrigido

### 4. Parsing silencioso de score/threshold (corrigido)
- **Severidade**: Alta
- **Arquivos**: step_handler.go, scoring_handler.go
- **Problema**: `strconv.Atoi` com `_` descartava erros, permitindo inputs invalidos
- **Correcao**: Funcao `parseScore()` com validacao explicita no step handler. `strconv.Atoi` com tratamento de erro no scoring handler
- **Status**: Corrigido

## Vulnerabilidades Aceitas (futuras melhorias)

### 5. CSRF Token
- **Severidade**: Media (mitigada)
- **Mitigacao atual**: Cookie SameSite=Lax
- **Recomendacao futura**: CSRF tokens explicitos (mesmo status da F04)

### 6. Security Headers (CSP, X-Frame-Options)
- **Severidade**: Baixa
- **Recomendacao futura**: Middleware de security headers (mesmo status da F04)

### 7. Rate Limiting em batch operations
- **Severidade**: Baixa
- **Mitigacao atual**: Batch limitado a 50 itens, auth obrigatorio
- **Recomendacao futura**: Rate limiting no router

### 8. LIKE ESCAPE clause
- **Severidade**: Baixa
- **Mitigacao atual**: `escapeLike()` escapa wildcards e backslashes. MySQL interpreta backslash como escape por padrao
- **Recomendacao futura**: Adicionar `ESCAPE '\\'` explicito na query

### 9. Validacao UUID em itens de array (document_ids[], mcp_ids[])
- **Severidade**: Baixa
- **Mitigacao atual**: Use case valida existencia via `docRepo.FindByID` antes de associar (retorna not found para IDs invalidos)
- **Recomendacao futura**: Validar formato UUID no handler antes de chamar use case
