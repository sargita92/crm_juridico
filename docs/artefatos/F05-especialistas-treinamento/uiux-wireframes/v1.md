# Wireframes e Fluxos — F05 Treinamento de Especialistas

## Principio geral

As funcionalidades de treinamento (RAG, MCPs, guardrails, steps, scoring) sao adicionadas como **novas secoes na tela de detalhe do especialista** ja existente (F04). Documentos e MCPs tambem tem **telas proprias de gestao** acessiveis pela sidebar. A experiencia e consistente com o padrao visual do admin ja implementado.

---

## Fluxo de navegacao (atualizado)

```
/admin/dashboard → sidebar
    ├── "Especialistas" → /admin/specialists (listagem existente)
    │     └── clique na linha → /admin/specialists/:id (detalhe, agora com novas secoes)
    │           ├── secao "Prompt" (existente)
    │           ├── secao "Tenants Associados" (existente)
    │           ├── secao "Documentos RAG" (nova)
    │           ├── secao "MCPs" (nova)
    │           ├── secao "Guardrails" (nova)
    │           ├── secao "Passo a Passo" (nova)
    │           └── secao "Qualificacao" (nova)
    ├── "Documentos" → /admin/documents (novo, gestao global)
    │     ├── botao "Novo Documento" → upload
    │     └── clique na linha → /admin/documents/:id (detalhe)
    └── "MCPs" → /admin/mcps (novo, gestao global)
          ├── botao "Novo MCP" → /admin/mcps/new (formulario)
          └── clique na linha → /admin/mcps/:id (detalhe)
            └── botao "Editar" → /admin/mcps/:id/edit
```

## Modal: Upload de Documento

- Overlay escuro + card centralizado (max-width 500px)
- Titulo: "Novo Documento"
- Campo **Nome** (text, obrigatorio, placeholder: "Nome do documento")
- Campo **Arquivo** (file input, obrigatorio)
  - Tipos aceitos: .pdf, .txt, .docx
  - Texto auxiliar: "PDF, TXT ou DOCX (max 10MB)"
  - Drag-and-drop zone com fallback para botao "Selecionar arquivo"
- Botao "Enviar" (cor primaria, loading: spinner + "Enviando...")
- Botao "Cancelar" (neutro, fecha modal)
- HTMX: `hx-post="/admin/documents"` com `hx-encoding="multipart/form-data"`
- Sucesso: fecha modal, atualiza tabela
- Erro: mensagens inline

### Secao: Passo a Passo

- Card com titulo "Passo a Passo (Script de Atendimento)"
- Botao "Adicionar Step" (canto superior direito) → abre modal de criacao
- Lista ordenada de steps (numerados):

```
  ┌─��────────────────────────────────────────────────────────────────┐
  │ #1  Qual o seu nome completo?                                   │
  │     Tipo: Texto livre | Obrigatorio                    [^][v][E][X] │
  ├──────────────────────────────────────────────────────────────────┤
  │ #2  Qual o numero do processo?                                  │
  │     Tipo: Texto livre | Obrigatorio | Pontuacao: 20    [^][v][E][X] │
  ├──────────────────────────────────────────────────────────────────┤
  │ #3  Possui documento de identidade?                             │
  │     Tipo: Documento | Opcional | Pontuacao: 10         [^][v][E][X] │
  └──────────────────────────────────────────────────────────────────┘
  
  [^] = mover para cima    [v] = mover para baixo
  [E] = editar             [X] = excluir
```

- Cada step exibe:
  - Numero da ordem
  - Texto da pergunta/instrucao
  - Tipo de dado esperado (badge)
  - Obrigatoriedade (badge "Obrigatorio" ou "Opcional")
  - Pontuacao (se configurada, exibida como "Pontuacao: X")
- Botoes de acao por step:
  - Mover para cima: `hx-post="/admin/specialists/:id/steps/:step_id/move-up"` com `hx-target="#steps-section"`
  - Mover para baixo: `hx-post="/admin/specialists/:id/steps/:step_id/move-down"` com `hx-target="#steps-section"`
  - Editar: abre modal de edicao
  - Excluir: `hx-delete` com `hx-confirm="Excluir este step?"`
- Primeiro step nao tem botao "mover para cima"; ultimo nao tem "mover para baixo"
- Estado vazio: "Nenhum step configurado" + botao "Configurar primeiro step"
- HTMX: secao carregada via `hx-get="/admin/specialists/:id/steps"` com `hx-trigger="load"`

### Secao: Qualificacao por Pontuacao

- Card com titulo "Qualificacao por Pontuacao"
- Exibido apenas se o especialista tem pelo menos 1 step com pontuacao > 0
- Se nenhum step tem pontuacao: mensagem "Configure pontuacoes nos steps acima para habilitar a qualificacao"

#### Resumo visual

```
  ┌──────────────────────────────────────────────────────────────────┐
  │  Qualificacao por Pontuacao                         [Configurar] │
  │                                                                  │
  │  Total possivel:  100 pontos                                     │
  │  Threshold:        70 pontos (70%)                               │
  │                                                                  │
  │  ████████████████████████████████░░░░░░░░░░░░░░  70/100          │
  │  ─────────────── qualificado ──│── desqualificado ──             │
  │                                                                  │
  │  Steps com pontuacao:                                            │
  │  • Numero do processo ............... 20 pts                     │
  │  • Documento de identidade .......... 10 pts                     │
  │  • Comprovante de endereco .......... 15 pts                     │
  │  • Descricao detalhada do caso ...... 30 pts                     │
  │  • Testemunhas disponíveis .......... 25 pts                     │
  └──────────────────────────────────────────────────────────────────┘
```

- **Barra visual**: barra de progresso mostrando threshold vs total
  - Parte preenchida (verde): zona de qualificacao
  - Parte vazia (cinza): zona de desqualificacao
  - Label com valor: "70/100"
- **Resumo numerico**:
  - Total possivel: soma dos pontos de todos os steps
  - Threshold: valor configurado + percentual
- **Lista de steps com pontuacao**: nome do step e pontos atribuidos
- Botao "Configurar" → abre modal de configuracao do threshold

### Modal: Configurar Threshold

- Overlay escuro + card centralizado (max-width 450px)
- Titulo: "Configurar Qualificacao"
- Texto informativo: "Total possivel: X pontos (soma dos pontos de todos os steps)"
- Campo **Threshold** (number input, obrigatorio, min 1, max = total possivel)
  - Placeholder: "Pontuacao minima para qualificacao"
  - Dica: "Leads que atingirem este valor serao qualificados"
- Preview em tempo real:
  - "Leads precisam de X de Y pontos (Z%) para serem qualificados"
  - Atualiza conforme o admin digita o valor
- Botao "Salvar" (cor primaria, loading state)
- Botao "Cancelar" (neutro, fecha modal)
- HTMX: `hx-put="/admin/specialists/:id/scoring"`, `hx-target="#scoring-section"`
- Sucesso: fecha modal, atualiza secao de qualificacao

## Padroes de interacao

### HTMX
- Todas as novas secoes no detalhe do especialista sao lazy-loaded via `hx-trigger="load"`
- Modais de associacao (documentos, MCPs) seguem mesmo padrao do modal de tenants da F04
- Formularios de guardrails e steps usam modais para criacao/edicao
- Reordenacao de steps via botoes (mover cima/baixo), cada clique faz `hx-post` e atualiza a secao
- Toggle de guardrails e inline (sem modal)
- Secao de scoring atualiza automaticamente quando steps sao alterados

### Feedback visual
- Toast/banner de sucesso apos cada acao (criar, editar, excluir, associar, desassociar, reordenar)
- Mensagens de erro inline nos campos dos modais
- Badges coloridos para tipos (guardrails, documentos, steps)
- Confirmacao antes de acoes destrutivas (excluir)
- Barra de progresso visual para scoring
- Contadores contextuais (ex: "3 documentos", "5 steps", "70/100 pts")

### Responsivo
- Secoes empilhadas em mobile (full-width)
- Modais full-screen em mobile
- Lista de steps com acoes em dropdown menu em mobile (em vez de botoes inline)
- Barra de scoring ocupa 100% da largura em mobile
- Tabelas de documentos e MCPs com scroll horizontal em mobile

### Consistencia com F04
- Modais de associacao (documentos, MCPs) seguem exatamente o padrao do modal de tenants
- Cards de secao seguem mesmo estilo visual (titulo + botao de acao no header)
- Loading states, badges, paginacao e estados vazios seguem padroes existentes
- Lazy-load de secoes via `hx-trigger="load"` (mesmo padrao da secao de tenants)
