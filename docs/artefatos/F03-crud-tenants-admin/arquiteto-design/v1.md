# Design Tecnico — F03 CRUD de Tenants (Admin)

## 1. Dominio

### 1.1 Entidade Tenant (existente — ampliar)

A entidade `Tenant` ja existe em `internal/tenant/domain/tenant.go`. Adicionar metodos de dominio:

```go
// Novos metodos na entidade Tenant

func (t *Tenant) Block(reason string) error {
    if reason == "" {
        return ErrBlockReasonRequired
    }
    if t.Status == TenantStatusBlocked {
        return ErrTenantAlreadyBlocked
    }
    if t.Status == TenantStatusInactive {
        return ErrTenantInactive
    }
    t.Status = TenantStatusBlocked
    t.BlockReason = reason
    t.UpdatedAt = time.Now()
    return nil
}

func (t *Tenant) Unblock(reason string) error {
    if reason == "" {
        return ErrUnblockReasonRequired
    }
    if t.Status != TenantStatusBlocked {
        return ErrTenantNotBlocked
    }
    t.Status = TenantStatusActive
    t.BlockReason = ""
    t.UpdatedAt = time.Now()
    return nil
}

func (t *Tenant) Deactivate() error {
    if t.Status == TenantStatusInactive {
        return ErrTenantInactive
    }
    t.Status = TenantStatusInactive
    t.UpdatedAt = time.Now()
    return nil
}

func (t *Tenant) Update(name string, tenantType TenantType, document string) error {
    // mesmas validacoes de NewTenant
    if name == "" {
        return ErrTenantNameRequired
    }
    if document == "" {
        return ErrTenantDocRequired
    }
    if tenantType != TenantTypePF && tenantType != TenantTypePJ {
        return ErrInvalidTenantType
    }
    t.Name = name
    t.Type = tenantType
    t.Document = document
    t.UpdatedAt = time.Now()
    return nil
}
```

## 4. Contratos HTTP

Todas as rotas sob `/admin/tenants` protegidas por middleware `authMw` + middleware `requireAdmin`.

### Middleware RequireAdmin (novo)

```go
// internal/shared/middleware/admin.go
func RequireAdmin() gin.HandlerFunc
// Verifica claims.Role == "admin", senao retorna 403
```

### Rotas

| Metodo | Rota | Handler | Request | Response |
|--------|------|---------|---------|----------|
| GET | /admin/tenants | RenderList | query: search, status, type, page | HTML (listagem) |
| GET | /admin/tenants/new | RenderCreateForm | — | HTML (formulario) |
| POST | /admin/tenants | HandleCreate | form: name, type, document | HTML (formulario com erro) ou HX-Redirect |
| GET | /admin/tenants/:id | RenderDetail | — | HTML (detalhe) |
| GET | /admin/tenants/:id/edit | RenderEditForm | — | HTML (formulario) |
| PUT | /admin/tenants/:id | HandleUpdate | form: name, type, document | HTML (formulario com erro) ou HX-Redirect |
| DELETE | /admin/tenants/:id | HandleDeactivate | — | HX-Redirect para listagem |
| POST | /admin/tenants/:id/block | HandleBlock | form: reason | HTML (detalhe atualizado) |
| POST | /admin/tenants/:id/unblock | HandleUnblock | form: reason | HTML (detalhe atualizado) |

### Respostas HTMX

- Formularios: retornam fragmento HTML do formulario (com erros inline) ou `HX-Redirect`
- Listagem: filtros retornam fragmento da tabela (`#tenants-table`)
- Bloqueio/desbloqueio: retornam fragmento do detalhe (`#tenant-detail`)
