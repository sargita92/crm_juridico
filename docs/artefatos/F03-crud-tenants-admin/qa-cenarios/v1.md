# Cenarios de Teste — F03 CRUD de Tenants (Admin)

## Story 1: Criar Tenant

### CT-01: Criacao com dados validos
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario com nome="Escritorio ABC", tipo="PJ", documento="12.345.678/0001-90"
- **Entao** tenant e criado com status "active"
- **E** admin e redirecionado para o detalhe do tenant

### CT-02: Criacao sem nome
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario sem nome
- **Entao** mensagem de erro "Nome e obrigatorio" e exibida
- **E** tenant nao e criado

### CT-03: Criacao sem documento
- **Dado** que o admin esta autenticado
- **Quando** submete o formulario sem documento
- **Entao** mensagem de erro "Documento e obrigatorio" e exibida

### CT-04: Criacao com tipo invalido
- **Dado** que o admin esta autenticado
- **Quando** submete com tipo diferente de PF/PJ
- **Entao** mensagem de erro "Tipo invalido" e exibida

### CT-05: Criacao com documento duplicado
- **Dado** que ja existe um tenant com documento "12.345.678/0001-90"
- **Quando** admin tenta criar outro com o mesmo documento
- **Entao** mensagem de erro "Documento ja cadastrado" e exibida

## Story 2: Listar Tenants

### CT-06: Listagem com dados
- **Dado** que existem 25 tenants cadastrados
- **Quando** admin acessa /admin/tenants
- **Entao** ve os primeiros 20 tenants (paginados)
- **E** cada linha exibe nome, tipo, documento, status, data de criacao

### CT-07: Listagem vazia
- **Dado** que nao existem tenants
- **Quando** admin acessa /admin/tenants
- **Entao** mensagem "Nenhum tenant encontrado" e exibida

### CT-08: Busca por nome
- **Dado** que existe tenant "Escritorio ABC"
- **Quando** admin busca por "ABC"
- **Entao** apenas tenants com "ABC" no nome sao exibidos

### CT-09: Busca por documento
- **Dado** que existe tenant com documento "12345678000190"
- **Quando** admin busca por "12345"
- **Entao** tenant correspondente e exibido

### CT-10: Filtro por status
- **Dado** que existem tenants ativos e bloqueados
- **Quando** admin filtra por status "bloqueado"
- **Entao** apenas tenants bloqueados sao exibidos

### CT-11: Filtro por tipo
- **Dado** que existem tenants PF e PJ
- **Quando** admin filtra por tipo "PJ"
- **Entao** apenas tenants PJ sao exibidos

### CT-12: Filtros combinados
- **Dado** que existem tenants PJ ativos e PJ bloqueados
- **Quando** admin filtra por tipo="PJ" e status="active"
- **Entao** apenas tenants PJ ativos sao exibidos

### CT-13: Paginacao
- **Dado** que existem 45 tenants
- **Quando** admin navega para pagina 2
- **Entao** ve tenants 21-40
- **E** paginacao mostra "Mostrando 21-40 de 45"

## Cenarios OWASP

### A01 — Broken Access Control

### CT-35: Escalacao de privilegio
- **Dado** que usuario "user" tenta POST /admin/tenants
- **Quando** envia request de criacao
- **Entao** recebe 403

### CT-36: IDOR — acesso a tenant por ID
- **Dado** que usuario "user" conhece o ID de um tenant
- **Quando** tenta GET /admin/tenants/:id
- **Entao** recebe 403

### CT-37: Manipulacao de metodo HTTP
- **Dado** que usuario "user" tenta DELETE /admin/tenants/:id
- **Quando** envia request
- **Entao** recebe 403

---

### A03 — Injection

### CT-38: SQL injection no campo de busca
- **Dado** que admin busca por `'; DROP TABLE tenants; --`
- **Quando** envia busca
- **Entao** busca retorna 0 resultados (sem erro de SQL)
- **E** tabela tenants permanece intacta

### CT-39: SQL injection no campo documento
- **Dado** que admin tenta criar tenant com documento `' OR 1=1 --`
- **Quando** submete formulario
- **Entao** documento e tratado como texto literal

### CT-40: XSS no campo nome
- **Dado** que admin cria tenant com nome `<script>alert('xss')</script>`
- **Quando** tenant aparece na listagem
- **Entao** HTML e escapado (exibido como texto, nao executado)

---

### A04 — Insecure Design

### CT-41: Tentativa de criacao sem autenticacao
- **Dado** que nao ha token
- **Quando** POST /admin/tenants com dados validos
- **Entao** recebe 401

### CT-42: Tentativa de bloqueio sem ser admin
- **Dado** que usuario "user" esta autenticado
- **Quando** POST /admin/tenants/:id/block com motivo
- **Entao** recebe 403

---

### A07 — Identification and Authentication Failures

### CT-43: Token expirado em operacao admin
- **Dado** que token esta expirado
- **Quando** tenta qualquer operacao em /admin/tenants/*
- **Entao** recebe 401

### CT-44: Token com role adulterado
- **Dado** que token foi manipulado para ter role="admin"
- **Quando** tenta acessar /admin/tenants
- **Entao** recebe 401 (token invalido por assinatura incorreta)

---

### A09 — Security Logging and Monitoring Failures

### CT-45: Log de acesso negado
- **Dado** que usuario "user" tenta acessar /admin/tenants
- **Quando** recebe 403
- **Entao** tentativa e registrada em log com user_id e rota
