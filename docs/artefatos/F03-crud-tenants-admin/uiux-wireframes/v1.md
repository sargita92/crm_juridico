# Wireframes e Fluxos — F03 CRUD de Tenants (Admin)

## Fluxo de navegacao

```
/dashboard → sidebar "Tenants" → /admin/tenants (listagem)
    ├── botao "Novo Tenant" → /admin/tenants/new (formulario)
    ├── clique na linha → /admin/tenants/:id (detalhe)
    │     ├── botao "Editar" → /admin/tenants/:id/edit (formulario)
    │     ├── botao "Bloquear" → modal de bloqueio (motivo obrigatorio)
    │     ├── botao "Desbloquear" → modal de desbloqueio (motivo obrigatorio)
    │     └── botao "Desativar" → modal de confirmacao
    └── filtros e busca atuam inline (HTMX, sem reload)
```

## Layout admin

- Sidebar fixa a esquerda (240px) com navegacao:
  - Logo + "CRM Juridico"
  - Dashboard
  - **Tenants** (ativo nesta feature)
  - (futuro: Especialistas, Pagamentos, Logs)
  - Rodape: nome do admin + botao sair
- Area de conteudo principal a direita com header contextual
- Responsivo: sidebar colapsa em mobile (hamburger menu)

## Tela: Listagem de Tenants (/admin/tenants)

### Header
- Titulo "Tenants"
- Botao "Novo Tenant" (canto direito, cor primaria)

### Filtros (barra acima da tabela)
- Campo de busca (placeholder: "Buscar por nome ou documento...")
  - HTMX: `hx-get="/admin/tenants"` com `hx-trigger="input changed delay:300ms"` e `hx-target="#tenants-table"`
- Select de status: Todos | Ativo | Bloqueado | Inativo
  - HTMX: `hx-get` no change
- Select de tipo: Todos | PF | PJ
  - HTMX: `hx-get` no change

### Tabela
- Colunas: Nome | Tipo | Documento | Status | Criado em | Acoes
- Status com badge colorido:
  - Ativo: verde
  - Bloqueado: vermelho
  - Inativo: cinza
- Coluna Acoes: icone de visualizar (olho)
- Linha clicavel (leva ao detalhe)
- Paginacao no rodape:
  - "Mostrando 1-20 de 45"
  - Botoes: Anterior | Proxima
  - HTMX: `hx-get` com page param, `hx-target="#tenants-table"`

### Estado vazio
- Icone ilustrativo + "Nenhum tenant encontrado"
- Se ha filtros ativos: "Limpar filtros"

## Tela: Formulario de Criacao (/admin/tenants/new)

### Header
- Breadcrumb: Tenants > Novo Tenant
- Titulo "Novo Tenant"

### Formulario (card centralizado, max-width 600px)
- Campo **Nome** (text, obrigatorio, placeholder: "Nome do tenant")
- Campo **Tipo** (select: PF | PJ, obrigatorio)
- Campo **Documento** (text, obrigatorio, placeholder muda conforme tipo: "000.000.000-00" para PF, "00.000.000/0000-00" para PJ)
  - Mascara de formatacao no input
- Botao "Salvar" (cor primaria, loading state: spinner + "Salvando...")
- Botao "Cancelar" (cor neutra, volta para listagem)
- HTMX: `hx-post="/admin/tenants"`, `hx-target="#form-container"`, `hx-swap="outerHTML"`
- Sucesso: `HX-Redirect` para detalhe do tenant criado
- Erro de validacao: re-renderiza formulario com mensagens inline nos campos

---

## Tela: Detalhe do Tenant (/admin/tenants/:id)

### Header
- Breadcrumb: Tenants > Nome do Tenant
- Titulo: nome do tenant
- Badges: tipo (PF/PJ) + status (colorido)

### Card de informacoes
- **Nome**: valor
- **Tipo**: PF ou PJ
- **Documento**: formatado (CPF ou CNPJ)
- **Status**: badge colorido
- **Motivo do bloqueio**: exibido apenas se status = bloqueado (card de alerta vermelho)
- **Criado em**: data formatada
- **Atualizado em**: data formatada

### Acoes (barra de botoes)
- **Editar** (cor primaria) → navega para formulario de edicao
- **Bloquear** (vermelho, exibido se ativo) → abre modal
- **Desbloquear** (verde, exibido se bloqueado) → abre modal
- **Desativar** (cinza, exibido se ativo ou bloqueado) → abre modal de confirmacao
- **Voltar** (neutro) → volta para listagem

---

## Tela: Formulario de Edicao (/admin/tenants/:id/edit)

- Mesmo layout do formulario de criacao
- Breadcrumb: Tenants > Nome do Tenant > Editar
- Campos pre-preenchidos com dados atuais
- HTMX: `hx-put="/admin/tenants/:id"`, `hx-target="#form-container"`, `hx-swap="outerHTML"`
- Sucesso: `HX-Redirect` para detalhe do tenant
- Erro: re-renderiza com mensagens inline

---

## Modal: Bloquear Tenant

- Overlay escuro + card centralizado (max-width 480px)
- Titulo: "Bloquear Tenant"
- Texto: "Ao bloquear, o tenant [nome] perdera acesso ao sistema."
- Campo **Motivo** (textarea, obrigatorio, placeholder: "Informe o motivo do bloqueio...")
  - Minimo 10 caracteres
- Botao "Bloquear" (vermelho, loading state)
- Botao "Cancelar" (neutro, fecha modal)
- HTMX: `hx-post="/admin/tenants/:id/block"`, `hx-target="#tenant-detail"`, `hx-swap="outerHTML"`
- Sucesso: fecha modal, atualiza detalhe com novo status
- Erro: mensagem inline no modal

---

## Modal: Desbloquear Tenant

- Mesmo layout do modal de bloqueio
- Titulo: "Desbloquear Tenant"
- Texto: "O tenant [nome] voltara a ter acesso ao sistema."
- Campo **Motivo** (textarea, obrigatorio, placeholder: "Informe o motivo do desbloqueio...")
- Botao "Desbloquear" (verde, loading state)
- HTMX: `hx-post="/admin/tenants/:id/unblock"`, `hx-target="#tenant-detail"`, `hx-swap="outerHTML"`

---

## Modal: Desativar Tenant

- Overlay escuro + card centralizado
- Titulo: "Desativar Tenant"
- Texto: "Tem certeza que deseja desativar o tenant [nome]? Essa acao pode ser revertida apenas por um administrador."
- Botao "Desativar" (vermelho, loading state)
- Botao "Cancelar" (neutro)
- HTMX: `hx-delete="/admin/tenants/:id"`, `hx-target="#tenant-detail"`, `hx-swap="outerHTML"`
- Sucesso: `HX-Redirect` para listagem

## Padroes de interacao

### HTMX
- Todos os formularios usam HTMX para submit sem reload
- Filtros e busca atualizam apenas a tabela (`hx-target`)
- Paginacao via HTMX (sem reload de pagina)
- Loading states em todos os botoes de acao (spinner + texto)
- Modais renderizados pelo servidor e injetados via HTMX

### Feedback visual
- Toast/banner de sucesso apos criar, editar, bloquear, desbloquear, desativar
- Mensagens de erro inline nos campos do formulario
- Badges coloridos para status
- Confirmacao antes de acoes destrutivas (desativar)

### Responsivo
- Tabela com scroll horizontal em mobile
- Formularios full-width em mobile
- Modais full-screen em mobile
- Sidebar colapsa em hamburger
