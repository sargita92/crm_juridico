# Wireframes e Fluxos — F14 Arquivos por Lead

## Princípio geral

A aba "Arquivos" é o terceiro ponto de entrada (depois de WhatsApp e Leads). A experiência é próxima de um gerenciador de arquivos leve: listagem densa, ícones por tipo, filtros visíveis, preview inline para imagens. Tudo server-side com HTMX — sem SPA, sem lazy-load custom.

Integra com o detalhe do lead (modal existente de F07) adicionando uma seção "Arquivos" com contagem e link para a aba geral filtrada.

---

## Fluxo de navegação

```
/tenant/files                       → lista geral (todos os arquivos do tenant)
    ├── filtros (tipo, período, busca, lead)
    ├── paginação
    ├── clique no item → preview inline (drawer lateral)
    │     ├── metadados
    │     ├── preview (imagem ampliada / player áudio / ícone)
    │     ├── botão "Baixar"
    │     └── botão "Abrir conversa" → /tenant/whatsapp?conversation=:id&message=:mid
    └── botão "Baixar" direto na linha

Modal de detalhe do lead (F07) atualizado:
    └── nova seção "Arquivos (12)"
          ├── thumbnails/ícones dos 6 últimos
          └── link "Ver todos" → /tenant/files?lead_id=:id
```

## Tela: Lista de Arquivos (/tenant/files)

### Wireframe (desktop)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Arquivos                                              1.234 arquivos         │
├──────────────────────────────────────────────────────────────────────────────┤
│ [🔍 Buscar por nome...]  Tipo:[Todos ▼]  Período:[Últ 30d ▼]  Lead:[—] [✕]  │
│ Filtros ativos: período: últ 30 dias  [limpar filtros]                       │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  ┌──┐  contrato-maria.pdf                       Maria Silva   2h   [↓][💬] │
│  │📄│  PDF · 1,2 MB · recebido                                              │
│  └──┘                                                                       │
│  ┌──┐  foto-documento.jpg                        João Pereira  4h   [↓][💬] │
│  │🖼│  JPG · 850 KB · recebido                                              │
│  └──┘                                                                       │
│  ┌──┐  audio-maria-silva.ogg                    Maria Silva   1d   [↓][💬] │
│  │🎵│  OGG · 320 KB · enviado · ▶ 0:42                                      │
│  └──┘                                                                       │

│  │📦│  ZIP · 4,1 MB · enviado                                              │

│                                                                              │
│  ◀ 1 2 3 … 42 ▶                                                             │
└──────────────────────────────────────────────────────────────────────────────┘
```

### Header
- Título "Arquivos" + contador total (respeitando filtros aplicados)
- Sem botão "criar" — arquivos entram automaticamente (Story 1)

### Barra de filtros
- **Busca** (campo): busca parcial case-insensitive por nome
  - HTMX: `hx-get="/tenant/files"` com `hx-trigger="input changed delay:300ms"`, `hx-target="#files-list"`, `hx-push-url="true"`, `hx-include="closest form"`
- **Tipo** (select): Todos, Imagem, Documento, Áudio, Vídeo, Outro
- **Período** (select): Todos, Hoje, Últ 7d, Últ 30d, Custom (abre inputs de data)
- **Lead** (auto-complete): pré-preenchido ao chegar de `/tenant/leads/:id`
  - HTMX: `hx-get="/tenant/files/leads-search?q=..."` com preview do contato
- **Linha "filtros ativos"**: chips com cada filtro aplicado + `[limpar filtros]`
  - Só aparece quando há pelo menos 1 filtro ativo
- Todos os filtros dentro de um `<form>` compartilhado — submissão unificada, sem reload

### Listagem
- Uma linha por arquivo, densa mas com folga visual
- **Colunas visuais**:
  - Thumbnail/ícone (48×48): imagens → thumb real; demais → ícone colorido por tipo
  - Nome do arquivo (bold, truncado com tooltip completo)
  - Metadados: tipo MIME · tamanho · direção (recebido/enviado)
  - Para áudios: player inline minimalista (▶ + duração)
  - Lead associado (nome do contato, clicável → detalhe do lead)
  - Tempo relativo (2h, 1d, 3d) — tooltip com data/hora absoluta
  - Ações: `[↓]` baixar, `[💬]` abrir conversa
- Linha inteira clicável → abre drawer lateral de preview
- Cursor pointer + hover discreto

### Estados
- **Vazio absoluto** (sem filtros): "Ainda não há arquivos nesse tenant. Quando você enviar ou receber mídia pelo WhatsApp, os arquivos aparecerão aqui." + ícone grande de pasta vazia
- **Vazio com filtros**: "Nenhum arquivo encontrado com esses filtros." + botão `[limpar filtros]`
- **Carregando**: skeleton de 6 linhas
- **Erro**: toast + botão "Tentar novamente"

### Paginação
- Padrão 25 itens/página
- Navegação numerada com elipses (`◀ 1 2 3 … 42 ▶`)
- HTMX: `hx-get="/tenant/files?page=N&..."` preservando filtros via `hx-include`

### Responsivo (mobile)
- Filtros colapsados num botão `[Filtros]` que expande um painel
- Linha simplifica: thumbnail menor, nome + tamanho + tempo, ações reduzidas a menu `⋮`
- Preview em drawer full-screen (bottom sheet)

Aberto ao clicar em qualquer linha. HTMX: `hx-get="/tenant/files/:id/preview"` com `hx-target="#file-drawer"`.

```
                              │ contrato-maria.pdf               [X]  │
                              ├────────────────────────────────────────┤
                              │                                        │
                              │         ┌────────────────┐             │
                              │         │                │             │
                              │         │   📄 PDF       │             │
                              │         │   (ícone ou    │             │
                              │         │    thumbnail)  │             │
                              │         │                │             │
                              │         └────────────────┘             │
                              │                                        │
                              │  Nome:       contrato-maria.pdf        │
                              │  Tipo:       application/pdf           │
                              │  Tamanho:    1,2 MB                    │
                              │  Direção:    Recebido                  │
                              │  Lead:       Maria Silva → (abre lead) │
                              │  Data:       05/04/2026 10:32          │
                              │                                        │
                              │  [↓ Baixar]     [💬 Abrir conversa]    │
                              │                                        │
                              └────────────────────────────────────────┘
```

### Variações por tipo
- **Imagem**: preview ampliado (até 600px de altura, max 100% do drawer). Clique → modal lightbox full-screen.
- **Áudio**: player HTML5 nativo (`<audio controls>`) com nome do arquivo.
- **Documento/vídeo/outro**: ícone grande centralizado + metadados.

### Ações
- **Baixar**: `<a href="/tenant/files/:id/download" download>` (link direto, não HTMX — browser gerencia download)
- **Abrir conversa**: link/redirect para `/tenant/whatsapp?conversation=:cid#msg-:mid`

### Fechamento
- `[X]` → HTMX `hx-get` vazio + remove classe `open` via `hx-swap-oob` (ou JS minimal toggle)
- Tecla ESC fecha

### Responsivo (mobile)
- Drawer vira bottom sheet (altura 85% da tela)

## Padrões de interação

### HTMX
- Filtros num único `<form>` com botão de submit implícito (cada select/input tem `hx-trigger` próprio com `hx-include="closest form"`)
- Paginação e trocas de filtro fazem `hx-push-url="true"` para permitir share/refresh
- Drawer carregado sob demanda (não pré-renderizado) — economia de DOM
- Link de download é `<a href>` puro, não HTMX (browser precisa controlar o stream)

### JS mínimo
- Toggle do drawer (abrir/fechar classe CSS) — função em `admin.js` semelhante a `toggleNotificationDropdown`
- Listener global de ESC para fechar drawer/lightbox
- Nada mais

### Feedback visual
- Toast de sucesso/erro nas ações (reusar componente existente)
- Skeleton loading na lista e no drawer (altura mínima consistente)
- Badge com contagem de arquivos no detalhe do lead
- Ícones por tipo com cores distintas (imagem=verde, documento=azul, áudio=roxo, vídeo=laranja, outro=cinza)

### Acessibilidade
- Drawer com `role="dialog"` e `aria-label`
- Lightbox focável (tab-trap simples)
- Ações de baixar/conversar com `aria-label` explicitando nome do arquivo
- Foco volta à linha originária ao fechar drawer

### Responsivo
- **Desktop (>= 1024px)**: layout descrito acima, drawer lateral 400px
- **Tablet (768–1023px)**: drawer vira modal centralizado 90% da largura
- **Mobile (< 768px)**: filtros colapsáveis, drawer como bottom sheet, lista compacta

## Observações para o Arquiteto

- A busca por nome é `LIKE` simples (sem full-text) — nome do arquivo é o único campo textual relevante
- Preview de imagem pode exigir endpoint específico `/tenant/files/:id/thumbnail` (lado servidor decide se redimensiona ou serve original)
- O link "Abrir conversa" precisa de ancoragem por `message_id` — alinhar com F06 se já suporta `#msg-:id`
- Considerar políticas de permissionamento (F08) — restringir lista a arquivos de leads visíveis pelo perfil do usuário; pode ser escopo de extensão futura se for complexidade demais no step 1
