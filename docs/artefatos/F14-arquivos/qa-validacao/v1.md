## Observações

1. **Captura outbound**: hook `StoreOutbound` implementado e coberto por teste unitário (adapter + use case), mas o fluxo ainda não é exercitado porque `SendMessage` só suporta texto (ver observação no design v1, item 12). Quando F06 adicionar envio de mídia, basta invocar o hook existente — **não bloqueia F14**.
2. **Diretório `storage/files/` do ambiente local ficou com dono `root` de uma execução Docker anterior** (fora do escopo desta feature). Recomendar à equipe ajustar permissão do diretório antes do próximo `go test ./...` local. Não afeta a DoD — os testes de integração usam `t.TempDir()` e `storage/files` só é criado pelo main no boot da app.
3. **Placeholder de contagem UI**: o total exibido em `/tenant/files` reflete todos os arquivos do tenant respeitando os filtros ativos (verificado em CT-12).
