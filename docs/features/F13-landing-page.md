# F13 - Landing Page

## Objetivo
Criar uma página de apresentação do produto para captação de novos clientes.

## Pré-requisitos
- nenhum (pode ser feita independente, prioridade baixa)

## Steps

### Step 1: Design
- [ ] UI/UX define layout, seções e conteúdo da landing page
- [ ] seções sugeridas: hero, funcionalidades, como funciona, depoimentos, preços, CTA
- [ ] responsiva (mobile-first)

### Step 2: Implementação
- [ ] template HTMX com layout dedicado (sem header de app)
- [ ] seções com conteúdo estático
- [ ] formulário de contato/interesse
- [ ] animações sutis (CSS)

### Step 3: SEO e performance
- [ ] meta tags adequadas
- [ ] open graph tags
- [ ] performance (lazy loading de imagens, CSS otimizado)

## Critérios de aceite
- página é bonita, intuitiva e responsiva
- formulário de contato funciona
- boa performance no Lighthouse
